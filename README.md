# 文言事实提取与生成｜9B 模型对照

本项目研究同一组事实写成文言后，语言模型能否读对人物、动作、时间、地点与数量，以及这些事实进入正文后是否保持准确。本文为开发阶段研究简报。

## 文言与白话交叉实验

以官方 Qwen3.5-9B 和项目版本 29862 对照。四个开发场景各有四组事实，以文言、白话两种等义条目呈现。模型分别直接提取事实、独立写白话稿、独立写文言稿，共生成 48 份答卷。成稿调用各自读取原条目。两模型使用相同输入模板与解码设置，采用 Q4_K_M 本地推理、温度 0.35、top-p 0.9、重复惩罚 1.12、固定种子 1729 和 160 token 上限。

| 模型 | 输入 | 直接提取 | 要求写白话 | 要求写文言 |
|---|---|---:|---:|---:|
| 官方 Qwen3.5-9B | 白话 | 15/16 | 12/16 | 14/16 |
| 官方 Qwen3.5-9B | 文言 | 12/16 | 9/16 | 13/16 |
| 29862 | 白话 | 14/16 | 11/16 | 10/16 |
| 29862 | 文言 | 10/16 | 11/16 | 13/16 |

每个分数按事实组计。一个事实组的关键条件须全部保留，例如数量、时点与动作须对应。成文列按请求的目标语体标记，实际语体需另评。

29862 读白话答对 14/16，读文言答对 10/16。文言提取的六组错误中，四组来自一个同时要求跟踪数量、地点与后续时点的场景。29862 直接写文言时得 13/16，相对于独立提取的三组恢复分别来自两个场景。这两个分数来自独立调用，无法据此判断串联提取到成文的效果。

## 下一步

从同一个官方 9B 底模出发，比较等步数、等训练 token 的文言原文与相近题材白话继续预训练。先用按来源留出的新原典检验事件组提取，逐项核对人物、动作、否定、时点、数量与原文证据，再检验事实经写作后的留存。公开事件论元标注可参考 [GuwenEE](https://github.com/Lyn4ever29/GuwenEE)，古籍自监督训练先例可参考 [GujiBERT 与 GujiGPT](https://arxiv.org/abs/2307.05354)。

## 范围

四个开发场景仅含 16 组独立事实。结果来自单一解码种子和未盲评的人工评分，适合定位可复核的错误类型。以上未估计总体准确率或继续预训练收益。
